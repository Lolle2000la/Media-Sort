## System Prerequisites

Every package below is self-contained: you never have to install the `mpv`
media playback engine libraries or `ffmpeg` yourself.

### Windows & macOS

**No manual setup is needed!** The precompiled packages for both Windows and macOS automatically bundle all required `libmpv` libraries natively inside the application bundle, along with dav1d for AVIF image support and ffmpeg for fast video thumbnails.

### Linux

Media Sort for Linux ships as an AppImage that is equally self-contained.

#### AppImage

The AppImage bundles everything it needs: `libmpv` (built together with ffmpeg,
libass, zimg and dav1d), the `ffmpeg` command line tool used for fast video
thumbnails, and the ALSA/PulseAudio and X11/Wayland libraries mpv links against.
**Nothing has to be installed on the host** — no `libmpv`, no `libdav1d`, no
`ffmpeg`, no codec packages. Because of that, the AppImage no longer depends on
the mpv version your distribution happens to ship, and video playback, AVIF
images and video thumbnails work the same everywhere.

What the host still has to provide:

- a 64-bit (x86_64 or aarch64) Linux desktop with an X11 or Wayland session,
- **glibc 2.35 or newer** (Ubuntu 22.04+, Debian 12+, Fedora 36+, current Arch) —
  the AppImage is built against that floor on purpose, so it also runs on older
  distributions than the one it was compiled on,
- a working graphics driver with Vulkan (preferred) or OpenGL, which renders the
  video frames. Driver libraries are deliberately **not** bundled, because they
  must match your kernel and GPU,
- optionally a VA-API driver from your distribution, which enables
  hardware-accelerated video decoding.

```bash
chmod +x MediaSort-*-linux-x64.AppImage
./MediaSort-*-linux-x64.AppImage
```

On a system without FUSE (for example inside a container), add
`--appimage-extract-and-run`.

:::note
Without a usable Vulkan/OpenGL driver the app still launches, but in-app video
preview cannot render frames. Hardware decoding additionally needs the VA-API
driver for your GPU, which comes from your distribution — the AppImage only
ships the API library, never the driver.
:::
