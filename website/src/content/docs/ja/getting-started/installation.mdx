Media Sortは、Windows、Linux、およびmacOS向けのプリコンパイル済みスタンドアロンパッケージとして利用可能です。

Media Sortはメディア再生やUI制御にネイティブのシステムAPIを統合しているため、お使いのプラットフォームのシステム要件を以下からご確認ください。

## システムの前提条件

以下に挙げるパッケージはいずれも自己完結しています。`mpv` メディア再生エンジンのライブラリや `ffmpeg` を自分でインストールする必要はありません。

### Windows & macOS

**手動のセットアップは不要です！** Windows版とmacOS版のプリコンパイルパッケージには、必要なすべての `libmpv` ライブラリがアプリケーション内に同梱されており、AVIF画像サポート用のdav1d、高速な動画サムネイル用のffmpegも含まれています。

### Linux

Linux版のMedia Sortは、同じく自己完結したAppImageとして提供されています。

#### AppImage

AppImageには必要なものがすべて同梱されています：`libmpv`（ffmpeg、libass、zimg、dav1dとともにビルド）、高速な動画サムネイル用の `ffmpeg` コマンドラインツール、そしてmpvがリンクするALSA/PulseAudioおよびX11/Waylandライブラリです。**ホスト側にインストールする必要はありません** — `libmpv`、`libdav1d`、`ffmpeg`、コーデックパッケージのいずれも不要です。そのため、お使いのディストリビューションが提供するmpvのバージョンに依存しなくなり、動画再生・AVIF画像・動画サムネイルがどこでも同じように動作します。

ホスト側で引き続き必要なもの：

- X11またはWaylandセッションを持つ64ビット（x86_64またはaarch64）のLinuxデスクトップ
- **glibc 2.35以降**（Ubuntu 22.04以降、Debian 12以降、Fedora 36以降、最新のArch）— AppImageは意図的にこの下限に対してビルドされているため、コンパイルした環境より古いディストリビューションでも動作します
- 映像フレームを描画するための、Vulkan（推奨）またはOpenGL対応のグラフィックスドライバー。ドライバーライブラリはカーネルとGPUに一致する必要があるため、意図的に**同梱していません**
- オプション：ディストリビューションが提供するVA-APIドライバー（ハードウェア支援による動画デコードが有効になります）

```bash
chmod +x MediaSort-*-linux-x64.AppImage
./MediaSort-*-linux-x64.AppImage
```

FUSEのない環境（コンテナなど）では `--appimage-extract-and-run` を付けて実行してください。

:::note
使用可能なVulkan/OpenGLドライバーがない場合でもアプリは起動しますが、アプリ内の動画プレビューはフレームを描画できません。ハードウェアデコードにはさらにGPU用のVA-APIドライバーが必要で、これはディストリビューションから提供されます。AppImageはAPIライブラリのみを同梱し、ドライバーは決して同梱しません。
:::
