## Systemvoraussetzungen

Alle unten aufgeführten Pakete sind eigenständig: Sie müssen die Bibliotheken
der `mpv`-Medien-Engine oder `ffmpeg` niemals selbst installieren.

### Windows & macOS

**Keine manuelle Einrichtung erforderlich!** Die vorkompilierten Pakete für Windows und macOS enthalten bereits alle erforderlichen `libmpv`-Bibliotheken direkt im Anwendungsbundle, zusammen mit dav1d für die AVIF-Bildunterstützung und ffmpeg für schnellere Video-Miniaturansichten.

### Linux

Media Sort ist für Linux als AppImage verfügbar, das ebenso eigenständig ist.

#### AppImage

Das AppImage enthält alles, was es benötigt: `libmpv` (zusammen mit ffmpeg,
libass, zimg und dav1d gebaut), das `ffmpeg`-Kommandozeilenwerkzeug für schnelle
Video-Miniaturansichten sowie die ALSA-/PulseAudio- und X11-/Wayland-Bibliotheken,
gegen die mpv gelinkt wird. **Auf dem Host muss nichts installiert werden** —
kein `libmpv`, kein `libdav1d`, kein `ffmpeg`, keine Codec-Pakete. Dadurch hängt
das AppImage nicht mehr von der mpv-Version Ihrer Distribution ab, und
Videowiedergabe, AVIF-Bilder und Video-Miniaturansichten funktionieren überall
gleich.

Was der Host weiterhin bereitstellen muss:

- einen 64-Bit-Linux-Desktop (x86_64 oder aarch64) mit X11- oder Wayland-Sitzung,
- **glibc 2.35 oder neuer** (Ubuntu 22.04+, Debian 12+, Fedora 36+, aktuelles Arch) —
  das AppImage wird bewusst _innerhalb_ von Ubuntu 22.04 kompiliert und läuft
  damit auf dieser Version und allem, was **neuer** ist; eine Distribution mit
  einem älteren glibc als 2.35 kann es nicht laden,
- die ALSA- (`libasound`), C++-Laufzeit- (`libstdc++`) und `libdrm`-Bibliotheken
  Ihrer Distribution. Das sind die Systemschnittstellen, an die die Plugins und
  GPU-Treiber Ihrer Distribution binden — mitgeliefert würden sie Audio und
  Videodekodierung brechen statt helfen; jede Desktop-Distribution bringt sie
  mit,
- einen funktionierenden Grafiktreiber mit Vulkan (bevorzugt) oder OpenGL, der die
  Videobilder rendert. Treiberbibliotheken werden bewusst **nicht** mitgeliefert,
  da sie zu Kernel und GPU passen müssen,
- optional einen VA-API-Treiber aus Ihrer Distribution, der die
  hardwarebeschleunigte Videodekodierung aktiviert.

```bash
chmod +x MediaSort-*-linux-*.AppImage
./MediaSort-*-linux-*.AppImage
```

Auf Systemen ohne FUSE (etwa in einem Container) zusätzlich
`--appimage-extract-and-run` verwenden.

:::note
Ohne funktionierenden Vulkan-/OpenGL-Treiber startet die Anwendung weiterhin,
kann aber keine Videobilder in der Vorschau rendern. Hardwaredekodierung
benötigt zusätzlich den VA-API-Treiber Ihrer GPU, der aus Ihrer Distribution
kommt — das AppImage liefert nur die API-Bibliothek, niemals den Treiber.
:::
